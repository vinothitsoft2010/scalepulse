# Day 7: Review and Rest

No implementation task is required. Use this as a review checkpoint and a recovery day.

## Review checklist

- Can you distinguish functional requirements, SLIs, SLOs, and SLAs?
- Can you explain why four workers did not yield four times the throughput?
- Can you describe what the Day 1 benchmark did and did not measure?
- Can you explain why the limiter needs shared Redis state?

Keep unresolved decisions visible. In particular, production SLOs, Redis failure policy, telemetry retention, and Cassandra partition sizing require evidence and operational context.
